# AjaExtension

Aja Assistant e scripts do Genesys para uso como extensao Chrome ou pela barra de favoritos.

## Favorito recomendado

Use o conteudo de `bookmarklet-carregador-completo.txt` como URL de um favorito do Chrome.

O favorito carrega:

```txt
https://kingoffjoss.github.io/AjaExtension/Loader.js
```

O `Loader.js` carrega o `content.js` e depois aplica o tema Brisanet pelo arquivo:

```txt
https://kingoffjoss.github.io/AjaExtension/theme-brisanet-patch.js
```

## Previa do tema

```txt
https://kingoffjoss.github.io/AjaExtension/tema-brisanet-preview.html
```

## GitHub Pages

Ative o GitHub Pages na branch `main` usando a raiz do repositorio.

Depois de publicado, estes links devem abrir:

```txt
https://kingoffjoss.github.io/AjaExtension/content.js

https://kingoffjoss.github.io/AjaExtension/theme-brisanet-patch.js
```
